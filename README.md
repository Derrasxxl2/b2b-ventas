# B2B — Venta de CRMs hiperpersonalizados

Repositorio comercial. Aquí vive todo lo necesario para vender **CRMs hechos a medida
del negocio del cliente**, no software genérico al que el cliente se tiene que adaptar.

La tesis es simple:

> Una pyme de servicios no necesita un CRM. Necesita **que su operativa desaparezca**.
> El CRM es el vehículo. Lo que se vende es horas de administración que dejan de existir.

El activo central de este repo es **el caso Ullate Roche**: una academia de danza y artes
escénicas que pasó de 3 personas en administración a 1 —y esa 1 ya no trabaja delante
del ordenador— con un sistema construido y desplegado en 5 días.
